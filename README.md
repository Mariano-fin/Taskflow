# TASKFLOW: Gestor de Tareas

*Proyecto para Bootcamp Fullstack Sence 2025-2026*

**Link de repositorio:** https://github.com/Mariano-fin/Taskflow


## Características actuales

- Añadir tareas en pantalla
- Diseño responsive
- Interfaz intuitiva
- Uso de modales para mensajes al usuario
- Simulación de carga de API con async/await


## Características por implementar

- Funcionalidad en botones
- Uso de localStorage para guardar información
- Uso de "fakeApi" para cargar tareas demo


## Métodos y herramientas utilizadas

- CSS
- HTML5
- JavaScript
